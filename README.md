# SkillWallet – FidBuddy

## 📌 Project Description

**SkillWallet** is a skill management project that helps users manage their skills, achievements, certificates, and digital wallet information.

**FidBuddy** is the assistant component of SkillWallet that helps users with skill-related information and basic guidance.

## 🚀 Features

* 👤 User skill management
* 💼 Digital SkillWallet
* 🏆 Achievement management
* 📜 Certificate ID generation
* 🤖 FidBuddy assistant
* 🔑 Unique Skill ID generation
* 💳 Unique Wallet ID generation

## ⚙️ Installation

### 1. Clone or download the project

Download the SkillWallet project to your computer.

### 2. Install Python packages

Open Command Prompt inside the project folder and run:

```bash
pip install flask
```

### 3. Run the application

```bash
python main.py
```

### 4. Open in Browser

Open:

```text
http://127.0.0.1:5000
```

## 🤖 FidBuddy

FidBuddy provides simple responses for user queries related to:

* Skills
* SkillWallet
* Certificates
* Help and guidance

Example:

```text
User: Hi

FidBuddy: Hi! How can I help you?
```

## 🔢 ID Generator

The `generator.py` file can generate:

```text
Skill ID
Wallet ID
Certificate ID
```

Example:

```text
Skill ID: SK-12345
Wallet ID: WALLET-123456
Certificate ID: CERT-12345
```

## 🎯 Project Goal

The main goal of SkillWallet is to provide users with a simple digital platform to manage their skills, achievements, and certificates in one place, with assistance from FidBuddy.
